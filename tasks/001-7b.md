# 001-7b Finishing a history continues from where the walk is

The chronological walk holds each history's state when it reaches a leaf. Finishing that history (terminal emission)
does not use it: it books the path again from its own prefix cache, which reuses about 57% of the steps, and replaying
is 48% of finishing time on a heavy draw (`var/diag/001-7a/report.md`). Finishing is 85-90% of the walk's time.

Make finishing continue from the state the walk holds at the leaf: book only what remains (the tail to the horizon,
and whatever the walk deferred), and produce exactly what finishing produces now. Show it is exact on the saved root
and a few minutes of the review root: the same histories, the same cash, obligations and Slope line per history, the
same question records, and the no-skip and no-future checks clean. Report the finishing time before and after on the
same draw. Deferred-question reconstruction is the next task, not this one. No cloud and no judgment calls.
