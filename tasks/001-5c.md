# 001-5c How big one draw's tree is

The chronological walk from the review date walks one draw at a time. On GitHub's runners, eight draws each walked
9,700-15,000 histories in 1,000 seconds without finishing (`slope measure-walk`, results in `var/remote/001-5b/`), so
a draw's tree size is unknown.

Estimate it without walking it all: Knuth's estimator (random probes from the root to a leaf, multiplying the number
of branches taken at each decision; the mean over probes estimates the number of leaves, and the same with each
step's cost estimates the walk's time). Use the walk's own branching, on one draw, with enough probes for a stated
interval, and say how the cost is spread across the tree's top-level branches. Put several draws in `run.txt`, each
within 20 minutes. Results in `var/` and your final message. No cloud and no judgment calls.
