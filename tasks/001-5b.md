# 001-5b One draw's whole tree, walk only

The chronological walk starts from the review date and handles one draw at a time; draws are independent. A
measurement (`var/diag/001-5a/measure_walk_sharing.md`) found the inline no-skip and no-future checks take 86% of
the time; the walk alone did 244 histories in about 25 seconds on one draw.

Measure what one draw's whole tree costs with the walk alone: a mode that walks a draw from the review date to the
end, without the inline checks, writing as it goes (histories so far, depth, elapsed time, peak memory) and a final
count when the tree is done. Check it locally for a minute. Put eight draws spread across the 512 in `run.txt`, each a
line that answers within 20 minutes, so we learn how many of them finish and how fast. Put the measurement's notes
in your final message and its data in `var/`; a worker changes only the product, so no notes under `tools/`. No
cloud and no judgment calls.
