decision's answer is never part of it.

question on day 117 (8 September) records collateral 543,307,087; with the later stay denial on day 122 (13 September)
removed, it is 534,293,846. `var/diag/001-6a/report.md` has the history; `var/diag/001-6a/check-0.jsonl` the
details. The likely cause is `Chain.collateral_required`, a read of the last stay whatever its date, inherited by
questions that are not about the stay.

Make the collateral a question reads come from the stays dated before it. Show it with the no-future check on that
draw for a few minutes (`uv run python -m tools.check_question_futures --walker chronological --root review --row 0`),
and keep the focused tests passing. No cloud and no judgment calls.
